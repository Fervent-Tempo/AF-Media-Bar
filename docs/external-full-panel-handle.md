# 外侧完整层入口（实验）

实验功能默认关闭，仅作用于任务栏媒体栏。开启后，栏内完整层横杠替换为任务栏朝向桌面一侧的独立入口；封面、文字、托盘及菜单原有的点击绑定保持现状。

## 使用

进入媒体栏任意可见区域时显示横杠，沿任务栏方向保持原入口位置。没有可见文字区时使用媒体栏中心。完整层及其入口设置仍需开启。

- 默认点击打开；也可以选择在横杠上连续悬停 0.5 秒打开，点击仍可立即打开。
- 离开横杠会取消悬停计时；媒体栏和横杠之间的窄过渡区域允许指针经过，离开整个区域后延迟 150 毫秒隐藏。
- 打开完整层后横杠隐藏，面板仍按原有失活和 Esc 规则关闭。重新进入媒体栏才能再次显示入口。
- 自动隐藏任务栏完全展开并稳定后才能显示入口。指针移到横杠后，任务栏可以自然收起；横杠保留原位置供此次操作，离开即隐藏。不修改 Windows 自动隐藏设置。
- 关闭实验恢复原入口，保留所选打开方式。悬浮模式不使用外侧入口。

## 实现边界

`TaskbarWindow` 持有小窗口，组合根注入创建工厂；窗口只处理呈现和指针衔接，不调用媒体业务。窗口不激活、不显示任务栏按钮，仅横杠按钮矩形接收输入；过渡区域不创建覆盖桌面的透明窗口。

完整层请求携带打开时保存的屏幕 DIP 锚点及朝向。外侧入口只请求打开，不将重复请求变为关闭；独立窗口不依赖已收起任务栏的当前位置。

仅入口可见期间检查指针，不新增全局 Hook。隐藏停止计时器，释放解除订阅。设置变化、拖动、菜单、剪枝、环境恢复与退出取消入口；任务栏主轴移动、尺寸或 DPI 变化使冻结几何失效。

## 验收

自动检查不能证明 Explorer、跨屏 DPI 或真实鼠标体验。需检查两种触发方式、快速进出、过渡区域、自动隐藏中的操作、关闭后不重开，以及禁用实验和退出后没有残留窗口或命中区域。

多屏混合 DPI、任务栏四边、Explorer 重建与锁屏恢复未覆盖的环境，均标记“待维护者验收”。本次实际验证记录见[实验功能调研与验证报告](experimental-feature-research.md)。
