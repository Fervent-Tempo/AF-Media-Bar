# 主题与外观

修改主题、强调色、材质、动效、背景采样、文字色、程序图标、托盘图标或跑马灯时读本文。

## 主题与字体

- 强调色来源和资源发布各只有一处；不能逐页面刷新或另建来源。DWM 窗口着色不能代替 SystemAccent。
- 应用主题必须保留 `updateAccent: false`，防止控件库覆盖用户自选色；高对比度优先于用户外观，材质、强调色和文字使用系统回退。
- 界面使用语义画刷；模拟壁纸预览和外观色板允许有说明的固定颜色，不能扩散到普通文案。
- 字体、字重经统一策略规范化和夹取；空字符串跟随系统，`null` 保留旧预设语义。WPF 与 Web 歌词共用同一条回退链。
- 主题切换必须刷新既有界面；不能缓存旧画刷或字体决定。新增或删除主题字段时按设置发布登记处理兼容。

## 材质与动效

- 材质能力回退链只有一处；调用方传能力，不在窗口、页面或控件里重复分支。原生版本适配留在适配器。
- 材质应用失败必须退到不透明主题表面，不能把窗口留在透明状态；装饰属性失败不得误判整个材质失败。
- 可获取焦点的顶层菜单使用系统材质；不抢焦点的通知统一经 `AttachNonActivatingTransient` 接入 Accent 路径。
- 菜单子项仍是 WPF Popup：不应用 DWM Mica/Acrylic，改用程序绘制 Accent 模糊，并以 alpha=1 的命中安全填充和圆角窗口区域避免透明命中；材质失败时退回不透明主题表面。非激活窗口的系统材质只是一块单色，不能把它当作可用回退。
- 浓度缺失时用默认值（60%），不能把 `null` 当零再夹到下限。
- 时长、曲线和降级统一由 `MotionPolicy` 决定；关闭系统动画立即落到终态，不保留不可见的连续动画。
- 透明表面的文字清晰度不能靠 `ClearTypeHint` 声称保证；修改文本渲染、Effect 或像素取整必须验证 96 DPI 与缩放 DPI。

## 背景采样与文字色

- 采样区域限于目标文字周围留白，不得把文字、悬停按钮、频谱画布或自身绘制喂回判断；独立区域不能合并成夹带中间组件的包围矩形。
- 采样后台执行并串行合并；结果经过取消、代际和释放检查后应用。移动、挂起、重建、关闭后的旧结果不得写 UI。
- 强制浅/深色停止自动采样并清理决定；高对比度优先。频谱与文字使用同一明暗决定，Web 歌词通过既有样式同步，不另采样。
- 空样本、透明样本或单色直方图无贡献时返回“无有效主色”，不能制造黑色或主题色结果。
- WPF 标题/歌手/性能文字不新增离屏 Effect；悬停模糊随收起、挂起和关闭清理。

## 程序图标与托盘图标

- 窗口和托盘分别按应用主题、系统模式选图；高对比度按系统底色选图。不能共用一个主题判断或写死一套运行时图标。
- `Interaction.UseNativeTrayIcon` 是独立开关；开启后按当前单击动作选择 AF/音频/输入设备/音量图形，关闭时回到原图标。动作切换和系统主题变化都要刷新 Shell。
- 托盘换图必须设置 `NIF_ICON`，失败保留旧图标，不能留空。HICON、Icon 和来源流按资源包所有权释放，不能重复销毁或失去旧引用。
- 图标素材必须声明为程序集 Resource；改路径时核对 XAML、项目与安装器引用。静态 ApplicationIcon 不能作为运行时主题图标证据。

## 跑马灯

- 原文用于测量、内容指纹和复制；动画不得改写文本、按整字符跳步或逐帧重测全文。测量匹配实际字体、DPI 和格式，并保留字形边缘空间。
- 滚动视口保持几何分配宽度并裁剪；两份绘制元素保留完整原文宽度和接缝，副本不参与命中。绘制宽度不能当作媒体栏最小长度。
- 同一内容的宽度/DPI 变化从当前位置续跑；文本或字体变化重新测量并从起读停顿开始。悬停、隐藏和显示关闭时暂停，恢复后继续，普通快照刷新不回跳。
- 无溢出或关闭连续动画时停止时钟并恢复对齐；卸载/替换时解除时钟和回调，旧代际不能启动新动画。

## 验证

真实桌面覆盖深/浅/混合背景、强制档、高对比度、应用主题与系统模式分别变化、托盘四类动作、材质成功与回退、透明/非激活通知、96/125%/150% DPI 与中英混排 Emoji。自动测试只证明局部策略，不证明合成、清晰度或阅读节奏。
