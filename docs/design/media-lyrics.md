# 媒体与歌词

修改来源发现、选择、自动跟随、媒体快照、封面、歌词取词或缓存时读本文。

## 来源与身份

- 第三方动态集合只有目录服务一个所有者；消费者读取稳定数组，不把会话引用当成生命周期保证。重建与退出等已有租约结束后释放旧实例；所有权锁内不调用第三方库或用户事件。
- `MediaSourceRegistry` 统一来源身份、别名、过滤和仲裁。`SourceId` 与 `SelectionKey` 在注册来源间唯一，既有值保持兼容；`Matches` 同时识别规范 ID 和别名，别名互不重叠。
- 来源允许策略必须在选择、自动跟随、菜单、快照、媒体命令和提供器补充前统一执行；过滤用大小写不敏感的规范身份，不持久化临时会话标识。
- SMTC 与独立来源并列。独立来源实现 `IIndependentMediaSourceProvider`，无 SMTC 时仍可被发现；Provider 负责轮询、读取、取消和释放，纯策略不持有外部资源。
- SMTC 会话关闭时控制对象可能被置空；用构造后不变的 `MediaSession.Id` 经 guard 取来源，访问控制对象前检查可用性。
- 网易云保留 `playingList` 与 `fmPlay` 两条内存路径；只有按身份查找失败才尝试 `currentIndex`，且曲名必须与 SMTC 对得上。酷狗走独立来源与内存读取，不匹配的会话不能继承封面、歌词或控制能力。
- 浏览器缺失后隐藏旧画面但保留短暂重建宽限；可唯一续接的原来源继承先后记录，多标签页不能只按浏览器名合并。

## 快照与选择

- 快照不可变；选择、过滤、自动跟随和异步结果都按代际丢弃迟到结果。手动选择立即生效，普通刷新不覆盖。
- 自动模式跟随最近开始或恢复播放的来源；后来居上跟随最近新增会话，包括暂停会话；指定应用优先在该应用有会话时优先呈现，否则回退自动选择。
- 同批首次发现的候选按当前选择、系统当前媒体会话和稳定键打破并列；仅切歌、元数据刷新或补充控制通道不改变先后。
- 空、零尺寸、无有效采样像素或单色直方图无贡献时返回“无有效主色”；主色缓存保存空结果并替换上一首，调用方使用当前主题强调色或系统高亮色。

## 歌词

- 来源目录和取词仲裁各有一处权威，设置页不复制来源表。`EnabledSourceIds` 的三态必须保留：`null` 全部、空数组零请求、非空只启用列出的来源；未知身份保留在设置中，使用时忽略。
- 提供器无状态、不读设置；选项由 `LyricsRequest` 传入。来源抛错、超时或自身取消只表示未命中，只有调用方取消向上抛；遗留任务异常必须被观察。
- 预算只限制等待，不保证第三方库内部请求终止。区分失败未命中与已确认无歌词，不能把暂时失败永久缓存成无歌词。
- 本地歌词来源优先于在线来源。低置信命中分两类：题名不符、歌手相反或版本描述冲突属「有反证」，一律让位给在线；仅缺歌手与时长佐证属「无佐证」，只在在线结果明显更强时让位，避免低分在线结果覆盖题名完全一致的文件。支持格式、目录和开关由 `LyricsSourceSettings` 与 `LocalFileLyricsProvider` 维护；读取失败继续既有回退，不能硬编码本机路径。
- 格式识别留在 `LyricsFormatDetector`，包装只有整段可解析时才按包装处理；损坏包装对原载荷做一次按行回退。正文、译文和音译共用规则，QRC 属性正文保留换行与实体解码。
- 行集合按起始时间升序；信息行过滤、占位标记和纯音乐提示由纯策略决定；纯音乐只显示标题时经取词侧返回无歌词。临时提示不能缓存为无歌词。
- 仅改呈现方式不重新取词；缓存失效由 `LyricsCacheInvalidationPolicy` 统一判定。缓存由所有者释放，清空/剪枝更新代际并取消在途请求；同会话切歌取消旧曲，旧请求清理不得移除替换请求的标记。
- 解析在取词侧完成，呈现层不在 UI 线程解析原始文本。
- 竖向标题与歌手由原生控件绘制，作为歌词不可用时的回退。只有已开启歌词且已有歌词行才创建 WebView2，切歌暂时无词时可短时保留现有实例。

## 验证

真实播放器覆盖网易云普通歌单/私人 FM、酷狗、浏览器、本地歌词、切歌/切源、手动与自动选择、暂停与恢复、断网、超时、缓存清空和退出。自动测试用受控快照和本地文本，不连接真实播放器或网络；未验证时写“待维护者验收”。
