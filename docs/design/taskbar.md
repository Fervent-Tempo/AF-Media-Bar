# 任务栏与悬浮宿主

修改宿主生命周期、停靠、几何、自动隐藏、避让、组件布局或退出顺序时读本文。

## 宿主模型

- 每个实际存在的任务栏 HWND 最多一个宿主；同一显示器重建时按 HWND 去重，不能靠显示器序号或缓存实例冒充。
- 支持任务栏宿主与 `WindowMode.FloatingBar` 独立宿主。任务栏横竖共享内容/外观配置，悬浮模式独立保存每屏几何；不得把一套几何复制到另一模式。
- 组合根拥有宿主与服务的创建顺序。宿主只负责 HWND、DPI、Popup 所有权、Z 序和状态转发，不拥有媒体、歌词、音频或文件算法。
- Explorer 重建先停旧宿主、撤销输入区域和订阅，再建新宿主；退出按“菜单/Popup → 恢复任务 → Raw Input → 托盘 → 媒体来源 → Host”的顺序停止。停止与 Dispose 必须幂等，超时有兜底。

## 停靠与几何

- 横竖任务栏、位置偏好、多屏和无效矩形统一使用物理像素；子窗口只写父客户区坐标，Shell 运动后不用过期屏幕矩形二次纠偏。
- 横向位置和厚度必须夹入任务栏；媒体栏过大时起点仍贴任务栏边缘，不得顶部越界。
- 固定长度夹在悬停层最小长度与所有横向宿主的安全区间交集之间；环境约束不得写回设置。
- 拖动与放置使用同一空闲区间基准。待定拖动不得吞点击，真正拖动必须阻止抬起点击；封面、文字和栏外手柄的命中边界分别验证。
- 栏外拖动手柄是独立 Popup，不参与内容布局、最小长度或背景布局；隐藏、挂起、剪枝和卸载都要停止其计时器并释放浮层。
- 每次几何应用同步组件显隐、文字宽度、跑马灯和输入区域；不得用 `ActualWidth` 或当前 `Canvas.Left` 累积推断。
- 动画只产生绘制帧，不覆盖逻辑目标；重定向从当前有效值开始，重复目标不重新计时，`SkipTransition` 立即落位。

## 自动隐藏与运动

- 任务栏矩形变化时冻结位置、尺寸、采样与输入；稳定后才恢复。运动或隐藏期间不执行占用区探测、`SetWindowPos` 或 `SetWindowRgn`，不阻塞 Shell 动画。
- 稳定收起显式隐藏宿主，不能只依赖父子窗口运动；展开只在有匹配定位时跟随，旧几何不得跨 HWND、DPI、尺寸或主轴复用。
- 恢复先落位置、输入区域和最终长度，再恢复交互与计时器。
- 无媒体且无保留组件时隐藏整个 HWND，不能留下透明命中窗口。
- 挂起立即清理悬停层、文字模糊、连接过渡和临时裁剪；运动中保留歌词画面，稳定后更新到最新内容。

## 避让与占用区

- UIA 在专用 MTA 后台线程串行执行；UI/Explorer 线程不得等待结果。超时不能演变成无限并发，退出不能被探测阻塞。
- 占用区同时保留 UIA、Shell 回退和外部窗口采集；外部区域用 Z 序与命中测试双重判断，避免本程序遮挡造成漏判。
- 外部窗口必须同时通过几何门禁和 Shell 所有者过滤；普通应用、截图和录屏工具不得改变安全区。
- 只发布当前代、未超时的不可变结果；旧代、跨 HWND 或过期缓存不得回写。收缩立即避让，扩大用至少两份、跨 200 ms 的成功样本确认。
- Shell 菜单、任务栏重建和探测失败时保留最后有效位置；不能把菜单子树或缺失小组件当成占用区。

## 组件布局

- 封面和媒体文字是固定前缀，可排序尾部只由顺序策略解析；设置列表与布局不得各存一份顺序。
- 显隐由三态布局策略 `ComponentLayoutPolicy.Resolve` 决定（Resident/Idle/Hover），宿主和控件不得另读开关重复判定；隐藏组件同时取消命中并清理 hover。
- 顺序与无媒体保留项是两张表；保留项区分 `null`、空列表和非空列表。封面和媒体文字不能作为无媒体内容，快速启动音符复用 Artwork ID。
- 封面保持原比例，超出策略范围留白而不裁剪；先定封面宽度，再分配文字和尾部组件宽度。
- 空布局隐藏宿主；静置层、悬停层和完整层的开关不能互相改写。

## 验证

真实 Windows 覆盖四边任务栏、多屏、DPI、Explorer 重启、首次隐藏启动、自动隐藏快速反向、多宿主、浮动模式四边折叠、拖动/点击边界、菜单/Popup 与退出。自动测试和截图不能代替这些场景；未验证时写“待维护者验收”。
