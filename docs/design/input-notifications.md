# 输入、托盘与通知

修改 Raw Input、全局点击/滚轮、托盘图标/菜单、提示或曲目通知时读本文。

## Raw Input

- 输入监听在专用后台消息循环线程注册 Raw Input；回调只复制必要数据并尽快返回，禁止查询 Shell 图标、等待 Dispatcher、写磁盘日志或执行媒体/网络算法。异常不得吞掉系统输入。
- 注册与注销、消息线程和窗口句柄必须成对释放；停止先阻止新事件，再退出消息循环并有界等待线程结束，最后清订阅。释放后的回调不得发布结果。
- 物理按键状态由输入服务消费，普通 View/ViewModel 不新增 Win32 按键或指针查询；媒体栏 WPF 状态与宿主原生拖动是既有职责边界。托盘命中和业务执行在 UI 线程。
- 鼠标组合滚轮的松键点击必须被一次性消费，判定在输入线程完成；不能用滚动后固定延时代替松键窗口，也不能吞掉紧随其后的真实点击。
- 每个事件至多发一条命令；切歌静默期和在途门禁由共享路由持有，不能每个宿主各自计时。旧代际、已释放宿主和指针离开后的延迟事件必须丢弃。

## 托盘与提示

- `ShellTrayIconService` 拥有图标和 Shell 通知接口；`MainWindow` 协调菜单和点击意图。托盘菜单复用紧凑浮窗，以当前托盘图标矩形为锚点，不能另建一套。
- 原生托盘图标是独立设置；开启后按当前单击动作选择 AF/音频/输入设备/音量图形，关闭时用原图标。主题变化、动作切换和设置变化都要刷新 Shell。
- 换图必须 `NIF_ICON`；失败保留旧图标，不留空。HICON、Icon 和流按资源包所有权释放。
- 提示只显示手势和结果，不附加第二段曲名/歌手；提示挂在各自封面/文字 ToolTip 实例，不挂根元素、不共用实例。关闭提示或选 Disabled 时不显示全局提示。
- 全局滚轮面只有一处判据；设备、音量、无媒体音符和局部组件走各自语义，频谱、性能及空白不回退全局动作。

## 曲目通知

- 首个有效快照只建基线；每曲第一次播放最多通知一次，不模拟播放队列。同曲补全只更新可见内容，不重显示、不延长停留。
- 窗口日常 Show/Hide 复用，仅退出真正关闭。首次 HWND 透明、屏外完成模板测量，尺寸稳定后再定位和启动计时；旧呈现回调必须淘汰。
- `SizeToContent` 独占尺寸，`MinHeight` 本地为零；`SetWindowPos` 使用 `SWP_NOSIZE`，只移动和夹取落点。窗口始终非激活，不抢焦点或输入法。
- 非纯色材质经 `AttachNonActivatingTransient` 接入，不能改普通 DWM 路径或启用 `AllowsTransparency`。
- 身份是有效连接快照的来源标识和标题，去空白、大小写不敏感；暂停切曲后等第一个播放快照。启用与全屏策略决定是否呈现，前台目标缺失回固定、主屏或首屏。
- 支持六位置、水平/垂直偏移、标题/歌手字号与颜色、拖动吸附、预设色和文字样式预览；落点按 DPI 转物理像素后夹入目标工作区，原生只移动。
- 封面与媒体栏、完整层共用 `ArtworkBoxPolicy`；`Uniform` 保留完整图像，无封面恢复方形占位。

## 验证

真实桌面检查冷/热启动鼠标不卡顿、图标外滚轮不生效、不影响其他应用输入、组合键松键不误点、下一次点击有效、指针离开后延迟滚轮无动作、托盘菜单锚点/反复开关/退出无残留。通知检查首条与后续尺寸、封面补全、六位置与偏移、拖动吸附、字号/颜色、全屏/焦点/输入法、DPI 和语言切换；自动测试不能替代这些场景。
