# 平台运行：音频、指标、日志、更新、名单与剪枝

修改音频、频谱、性能指标、日志、更新/安装、关于页名单或后台剪枝时读本文。

## 音频

- WASAPI、Core Audio、进程读取与设备切换留在注入服务；ViewModel/宿主只协调状态、菜单和输入意图，控件只呈现。不得把平台算法写进界面。
- 设备列表按显示名再按标识稳定排序，默认设备只决定选中项。设备滚轮先更新提示，静止约 1.2 秒后应用最后候选；旧候选按版本淘汰，不能把中间值写进系统。
- 应用音量跨全部活动渲染端点按进程聚合，多会话取平均，全部静音才算静音；写入覆盖该进程全部匹配会话，不迁移已有音频流。
- 音量每格 2%，夹取 0–100，连续调节按约 100 ms 合并；设到零以上同时解除静音。任务栏和托盘滑杆使用显式音频样式，不启用设置页滑杆行为，避免抢占音频滚轮。
- 设备/音量菜单先由局部音频语义接管，菜单内滚轮也继续调节同一候选，不能落回播放器全局手势。
- 图标从会话路径或可执行文件读取，正确掩码合成到 ARGB 后编码 PNG，不把 `Icon.Save` 的掩码 DIB 直接交给 WPF。系统声音按 PID 0 识别，不依赖会话的 `IsSystemSoundsSession`。
- 设备名、应用名和品牌格式名原样显示；程序产生的状态、错误和系统声音名称通过本地化资源。空间音效配置交给系统入口。

## 频谱与性能指标

- 只在控件实际可见时取样并持有指标租约；按三态布局策略和控件实际显隐判断，不能只读设置开关空转。隐藏或停止后停止周期端点扫描，恢复时能重新唤醒。
- 端点解析在后台；区分“静音但连接”“已拔除”“枚举失败”。静音保留目标，拔除丢弃失效标识并回退默认，失败保留缓存等待重试。
- 频段边界严格递增并保持 45 Hz–20 kHz。静音时柱与像素保留最小槽位；波形闭合且关于垂直中线对称。
- 柱数、样式或内容高度变化必须发布尺寸请求，不能被内容指纹去重吞掉。高度不改变占用宽度；横轴尺寸与文字悬停块一致。
- 四种样式共用动画时长和跟随参数；追平或卸载时停止逐帧计时器。频谱沿用媒体文字前景色，只改变自身不透明度；高对比度不降低系统画刷透明度。
- 频谱表面不能参与背景采样，避免自反馈；性能块与频谱各有外层悬停表面，显隐、悬停和命中落在外层，不参与全局滚轮。
- 性能消费者共享租约监视器；无租约停止采样，指标并集没有 GPU 时不创建或保留 GPU 查询。间隔按秒显示并吸附 0.5 秒网格，界面读数与滑杆位置一致。
- 网络指标用有效接口计数差和实际采样间隔计算；首采样、接口变化、计数回退及剪枝恢复重建基线，不用累计字节冒充速率。

## 日志与诊断

- 日志队列有界且不等待磁盘；满时丢最旧并保留新条目，Error 也遵循同一规则。调用方不等待磁盘，日志异常不向业务抛出。
- 日志文件 5 MiB × 5 轮转，后台写入；退出和部分崩溃入口做有界刷新，不承诺强杀或磁盘故障下零丢失。
- 高频状态按有意义变化去重，帧级细节用 Verbose；不记录歌曲以外的敏感内容，不新增遥测或联网行为。
- 媒体、设置、音频、停靠、更新和退出的关键变化使用统一日志服务；不能只写 Release 下无记录的调试输出。
- 开发者工具命令只做固定动作，不解释脚本或部分命令；预览与生产通知/重启确认隔离，关闭取消未完成请求但不撤销已提交的进程交接。
- Debug 持续性能记录只在 Debug 启动时自动开启；记录资源和 Raw Input 延迟，不记录歌曲、歌词、命令行或用户文件路径。文件按 JSONL v2 写入并有界轮转。

## 更新与安装

- 完整性和路径可信必须保留：只安装更新目录内的可信 `.exe`，安装前核验记录与文件，不安装旧版本或越界路径。`packages[].sha256` 是完整性依据，声明长度不能替代哈希。
- 清单保持追加式契约；非法或高于支持版本时拒绝，缺安装包降级手动下载，未知字段忽略。镜像哈希及双方声明长度必须一致。
- 发现新版本不自动下载；下载就绪后按既有启动时机交接，立即重启需显式请求。便携版不自动安装，有其它实例时推迟。
- 取消在交接提交点之前生效；一次性提交后完成清记录、释放互斥体和启动顺序，避免清记录后丢失待安装状态。退出在 Host 停止后、释放看门狗前有界等待，最多 5 秒，不在 UI 线程重算哈希。
- Inno 的 `AppId`、`AppMutex` 与程序侧一致；升级回原目录，卸载只清理本次安装的当前用户启动项，不删除用户设置和更新缓存。
- 发布资料、亮点和贡献者快照由发布流程维护；普通开发不修改线上字段、稳定通道或发布清单。

## 关于页名单

- 端点、回退和覆盖变量集中在来源策略，固定链接和素材路径集中在链接目录，不散入 XAML；不擅自增加代理、接口或联网行为。
- 覆盖地址替换对应名单/快照计划并绕过缓存，不追加到默认序列；贡献者仍先访问 GitHub API，失败回退快照。
- 取数失败不抛到界面，保留可用旧内容并可重试；合法空赞助名单与获取失败区分，部分成功不覆盖可用内容，高于支持版本拒绝。
- 缓存、头像和 HTTP 资源由服务释放；绑定更新回 UI，取消或释放后不回写过期状态。收款素材按通配嵌入，保留版权声明和许可清单。

## 后台剪枝

- 参与者只释放自己的资源，协调器不直接操作窗口、控件或其他服务缓存；宿主订阅、消息窗口和原生通知句柄成对释放，重复停止安全。
- 档位路径只由 `MemoryPrunePolicy` 决定；电源消息与 UI 资源处理留 UI 线程，耗时回收后台执行，失败记录后回退。
- 回收不改变当前曲目、封面引用和进度，不打断播放、拖动与悬停；只清可重建资源，恢复懒加载，不用预热拖慢 Shell 或输入。
- 深度回收只用于 L2/L3 和明确的按需例外；自动隐藏只走 Gentle，不交还工作集，等待期内恢复可见或宿主关闭时取消请求。
- L2/L3 释放歌词合成控件并丢弃该实例的待处理工作。恢复后由可呈现的宿主按需创建，等待期间显示曲目元数据。
- 后台评估周期、合并、节流和重入保护保持有效；启动评估有界并自停，退出后不发布结果，单个参与者失败不阻断其余恢复。
- 不在常规推进路径主动 GC；改变 GC 配置或宣传收益前做同场景对照，同时看提交量、恢复延迟和功能完整性。
