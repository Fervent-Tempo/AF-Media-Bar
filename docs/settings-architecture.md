# 实验入口与配置

当前分支只实现第一批：实验开关、配置边界与现有设置页复用。音频后台、新旧菜单切换、实际竖向呈现和桌面悬浮宿主均保留 main 基线，尚未接入实验开关。此批不能作为完整功能或发布候选验收。

## 唯一设置入口

实验性功能页只提供三个默认关闭的开关、风险提示、共享配置说明和导航按钮，不嵌入交互、内容与布局或外观页面，也不创建另一套编辑器。

音频设备列表、高级切换策略和输入映射继续放在原交互页；输入组件、排序和无媒体保留项仍在内容与布局页。关闭音频实验后隐藏相应选项及专属搜索结果，保存的偏好保留。开关打开后仍使用原来的设置键和 ViewModel。

任务栏横竖共用现有配置和页面。朝向不决定组件顺序等选项的可用性；竖向运行适配属于第三批。

悬浮实验开启后，现有内容与布局、外观、歌词和交互页提供“编辑配置”选择器，区分任务栏和桌面悬浮。实验页的跳转可直接选中相应目标。这个选择只改变编辑对象，不修改运行模式、不创建窗口，也不宣称悬浮宿主已实现。悬浮的可用长度预算仍须由后续宿主提供，本批禁用该预算编辑，避免套用任务栏的范围。

## 配置与重置

`ISettingsConfiguration` 明确目标、取消和重置范围，`LegacySettingsConfiguration` 将任务栏映射到原根字段，将桌面悬浮映射到 `FloatingBar.Profile`。悬浮配置首次开启时从任务栏初始化，之后独立保存和重置；每份配置内部横竖共用。

应用主题、字体、语言、媒体来源、取词规则、托盘交互和音频策略仍以全局值为准。呈现投影只应用外观和交互记录中的宿主字段，编辑全局字段不能覆盖另一目标的外观或媒体栏绑定。

内容与布局、外观、歌词重置仅作用于当前目标及各自页面的字段；普通页在音频实验关闭时保留隐藏的输入设备偏好。交互页重置在开启实验时同时恢复可见的全局音频策略，关闭时保留隐藏策略。所有默认值优先使用用户默认快照，全部重置保留既有一次性兼容提示语义。

新字段登记为 `unreleased`，schema 仍为 2；旧字段及枚举值保留，不迁移未发布开发构建的中间格式。预留的悬浮运行枚举仍归一化到任务栏，配置选择器不能绕过该运行边界。

## 上下文与生命周期

`SettingsContextService` 拥有窗口会话、后台环境查询、编辑目标与订阅。切换目标先提交草稿、取消旧作用域，再激活对应缓存；关闭悬浮实验时返回任务栏配置，并拒绝旧目标的迟到写入。环境刷新不会覆盖用户正在编辑的配置目标。

`SettingsPageCatalog` 区分配置可编辑和宿主已实现。`SettingsPageProvider` 复用唯一页面；`SettingsPageScopeCache` 拥有页面 DI 作用域，全局页面使用中立配置上下文，避免关闭悬浮实验后全局开关或字体页失效。设置窗口关闭时释放全部作用域和订阅。

导航有八个主入口和两个页脚入口。搜索使用稳定页面键和 `GroupId`，音频专属结果随开关过滤，旧页面及分组入口继续映射到当前唯一页面。DI 组合仍统一位于 `App.xaml.cs`。

## 验证边界

自动回归覆盖缺字段默认关闭、设置及用户默认快照、两份配置隔离、横竖共享、重置、隐藏偏好保留、旧作用域取消、编辑目标不改运行模式、真实 XAML 的显隐和导航意图，以及实验页不再嵌套页面。

真实设置窗口的跳转、目标选择、滚动定位、重置、切换语言及关闭再打开均待维护者验收。第二批音频运行时门禁、第三批竖向宿主和第四批悬浮宿主在各自批次接入并验收，本分支不包含这些实现。
