# 显示模式与设置入口

任务栏与桌面悬浮为正式显示模式。任务栏朝向跟随所选显示器的真实系统任务栏；悬浮支持横向、竖向及桌面或置顶层级。设置页跟随运行协调器已提交的模式，切换失败继续显示和编辑原模式。完整 Windows 场景仍待维护者验收。

## 唯一设置入口

“显示与位置”提供模式选择及当前模式的显示器、方向、位置选项。实验页仅保留尚在试验的功能，不再提供竖向任务栏和桌面悬浮开关；旧实验分组与通知入口重定向到正式页面。

任务栏横竖共用现有配置和页面，朝向不决定组件顺序等选项的可用性；竖向呈现见[竖向任务栏](vertical-taskbar.md)。音频设备与策略由设备管理及交互页维护，不受已移除的音频实验开关限制。

## 配置与兼容

`ISettingsConfiguration` 明确当前模式、取消与重置范围。`LegacySettingsConfiguration` 将任务栏几何映射到原根字段，将桌面悬浮几何映射到 `FloatingBar.Profile` 中的 BarDisplaySettings。悬浮几何首次选择或恢复缺失配置时从任务栏初始化，之后独立保存和重置；横竖朝向不增加配置副本。

应用主题、字体、外观、歌词呈现、组件、交互、语言、媒体来源、取词规则与音频策略使用全局配置。投影仅覆盖宿主几何，不复制共用外观或交互设置。页面重置恢复各自的共用字段与当前模式几何，不改另一模式几何；用户默认快照优先，全部重置保留既有一次性兼容提示语义。

`v1.5.0` 已发布的 `experiments.floatingBar`、`experiments.verticalTaskbar` 保留读取及序列化，但不再作为门禁。当前运行模式仍由保存的 WindowMode 和协调器决定，不因解除实验门禁自动切换。已有悬浮位置、目标和独立几何保留；旧版程序自身的实验规则不变。

设置 schema 保持 2。新增 `floatingBar.edgeCollapseEnabled` 默认开启，显式关闭值继续保留；位置记录的可选 `dockEdge` 缺失或无效时按未附着处理，运行时可根据正常位置重新判定贴边，首次实际收起时回填一次正常中心和附着边。新增字段与枚举标记 `unreleased`，已发布字段的登记以正式 tag 为准。

## 桌面边缘折叠

开关位于“显示与位置 → 桌面悬浮设置”。媒体栏拖到所属显示器工作区四边后可自动收起，保留边缘提示条；靠近或点击提示条展开，离开缓冲区后收起，拖离边缘解除附着。位置锁定不禁止展开和收起，关闭开关立即恢复正常位置。

折叠由单个 FloatingBarWindow 持有状态、动画和观察计时器，纯几何策略不访问平台。正常中心与附着边参与布局和保存，动画中的屏幕外坐标不写设置；尺寸、方向、工作区和 DPI 改变后重新锚定。原生裁剪同时限制显示与命中区域，防止相邻屏幕露出隐藏内容。

本宿主的菜单准备及打开、音频浮窗、完整面板和拖动期间不自动收起。完全收起时停止正文呈现采样并保留唤醒观察；无媒体隐藏时提示条也隐藏。挂起、重建和退出停止计时器与动画、失效旧租约并清理原生区域。动效遵循全局 MotionPolicy，关闭系统动画时即时切换。

## 上下文与生命周期

SettingsContextService 拥有窗口会话、后台环境查询、当前模式与订阅。模式或显示环境变化先取消旧页面工作，再激活对应缓存；运行切换期间拒绝写入，旧上下文不能提交迟到结果。

SettingsPageCatalog、SettingsPageProvider 和 SettingsPageScopeCache 统一页面、搜索及作用域。全局页面使用中立配置上下文，设置窗口关闭时释放全部作用域和订阅；稳定页面键及 GroupId 不依赖显示标题，DI 组合仍位于 App.xaml.cs。

## 验证边界

自动回归检查配置及默认快照、宿主几何隔离、模式门禁解除、上下文取消、四边几何、原生裁剪及宿主挂起。真实设置跳转、模式切换、贴边拖动、菜单交互、多屏/DPI、Explorer 恢复、重启和退出仍待维护者验收；构建或受控窗口检查不能替代实机通过。
