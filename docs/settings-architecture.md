# 实验入口与配置

已实现音频、竖向任务栏与桌面悬浮实验入口。设置页跟随运行协调器已提交的模式；共用呈现配置与各宿主几何分别维护，真实 Windows 场景仍待维护者验收。

## 唯一设置入口

实验性功能页只提供三个默认关闭的开关、风险提示、共享配置说明和导航按钮，不嵌入交互、内容与布局或外观页面，也不创建另一套编辑器。

音频设备列表、高级切换策略和输入映射继续放在原交互页；输入组件、排序和无媒体保留项仍在内容与布局页。关闭音频实验后隐藏相应选项及专属搜索结果，保存的偏好保留。运行时恢复 1.4.0 的输出设备选择及音量面板，复用音频服务；输入、应用路由、黑名单和高级策略在执行边界受开关限制，旧请求与弹层在切换时失效，已有 Windows 路由偏好不自动清除。开关打开后仍使用原来的设置键和 ViewModel。

任务栏横竖共用现有配置和页面。朝向不决定组件顺序等选项的可用性；竖向呈现见[竖向任务栏](vertical-taskbar.md)。

设置页只编辑当前已提交的运行模式，不提供独立于运行模式的配置切换。悬浮编辑器使用独立工作区预算，不套用任务栏图标避让范围；切换失败继续显示和编辑原模式。

## 配置与重置

`ISettingsConfiguration` 明确当前模式、取消与重置范围。`LegacySettingsConfiguration` 将任务栏几何映射到原根字段，将桌面悬浮几何映射到 `FloatingBar.Profile` 中的 BarDisplaySettings。悬浮几何首次开启时从任务栏初始化，之后独立保存和重置；横竖朝向不增加配置副本。

应用主题、字体、外观、歌词呈现、组件、交互、语言、媒体来源、取词规则与音频策略使用全局配置。投影仅覆盖宿主几何，不复制共用外观或交互设置。

页面重置恢复各自的共用字段与当前模式几何，不改另一模式几何；音频实验关闭时保留隐藏偏好。默认值优先使用用户默认快照，全部重置保留既有一次性兼容提示语义。

新字段登记为 `unreleased`，schema 仍为 2；旧字段及枚举值保留，不迁移未发布开发构建的中间格式。悬浮运行枚举仅在对应实验开启时生效；启用实验和编辑配置均不自动切换运行模式。

## 上下文与生命周期

`SettingsContextService` 拥有窗口会话、后台环境查询、当前模式与订阅。模式或显示环境变化先取消旧页面工作，再激活对应缓存；运行切换期间拒绝写入，旧上下文不能提交迟到结果。

`SettingsPageCatalog` 区分配置可编辑和宿主已实现。`SettingsPageProvider` 复用唯一页面；`SettingsPageScopeCache` 拥有页面 DI 作用域，全局页面使用中立配置上下文，避免关闭悬浮实验后全局开关或字体页失效。设置窗口关闭时释放全部作用域和订阅。

导航有八个主入口和两个页脚入口。搜索使用稳定页面键和 `GroupId`，音频专属结果随开关过滤，旧页面及分组入口继续映射到当前唯一页面。DI 组合仍统一位于 `App.xaml.cs`。

## 验证边界

自动回归覆盖缺字段默认关闭、设置及用户默认快照、宿主几何隔离、共用字段与横竖共享、重置、隐藏偏好保留、旧作用域取消、环境刷新不改运行设置、真实 XAML 的显隐和导航意图，以及实验页不嵌套页面。

真实设置窗口的跳转、运行模式切换、滚动定位、重置、切换语言及关闭再打开均待维护者验收。音频与竖向批次已接入运行时；悬浮宿主已接入，Windows 场景仍待维护者验收。竖向批次的实际 Windows 场景另行记录，自动检查不能代替实机通过。

设置类型按功能归组，AppSettings 定义数据模型，SettingsManager 保留通知与重置门面。设置文件格式、枚举值与默认语义未因文件整理而变化。
