# 设置页的关联入口

- 跨页的相关设置放在相关分组的末尾，使用 `AfSettingsRelatedLinksStyle` 容器和 `SettingsNavigationButton`，不穿插在参数行之间或独立放到页头。
- 按钮使用公共中性底色、细边框、留白、右箭头和焦点反馈；不在页面中复制模板。
- 单个目标使用目标页在侧栏中的名称，例如频谱、性能和蓝牙电量指向「常驻状态」。同一目标页的不同分组使用真实分组名称区分，避免出现多个同名按钮。
- 同一来源分组内，相同页面和分组只保留一个入口。导航参数保留稳定页面键与分组键，由导航目录解析旧入口。
- 只控制当前设置行的配置入口留在该行右侧；教程的「前往配置」、分类页卡片、快速开始磁贴和不可用功能的前置配置提示不属于关联入口，保留各自位置。
- 页头父级分类文字常态使用次要文字色，悬停或键盘聚焦时使用主要文字色；焦点边框仍须可见。

组件排序列表在拖动提示后补充「也可在实际媒体栏上用鼠标拖动组件」。设备、歌词来源、第二行内容和快速启动应用等排序列表沿用各自提示，避免把媒体栏组件手势用于其他列表。
