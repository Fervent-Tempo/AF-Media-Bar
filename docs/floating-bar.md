# 桌面悬浮条

桌面悬浮条由实验开关控制。开启后在实验页明确选择运行模式；任务栏和悬浮互斥。关闭实验切回任务栏，保留悬浮配置。实际运行状态仅在所有目标宿主成功激活后发布，失败保留原宿主并显示提示。

## 配置与位置

悬浮使用独立 Profile，横竖共享，主题、字体、语言、媒体来源、取词规则和音频实验策略保持全局。现有设置页面复用该 Profile；长度预算独立聚合各工作区，不使用任务栏图标预算。

每个选中显示器一条，原生窗口不附着 Explorer。位置以所属工作区相对 DIP 保存。拖动限制在该工作区，越过系统拖动阈值才捕获，拖后抑制合成点击；锁定时保留普通点击。方向、长度与 DPI 更新保留中心并夹区，临时显示器回退不覆盖原目标和位置。

## 生命周期

App.xaml.cs 注册协调器、平台服务和窗口工厂。MainWindow 转发快照、处理完整面板与拓扑；窗口持有控件、菜单、取消源、计时器与采样租约，不持有共享业务服务生命周期。

准备阶段不显示新宿主。协调器挂起旧宿主后激活候选，成功提交再释放旧宿主；失败或取消释放候选并恢复旧宿主。Explorer 重启、显示器变化和睡眠恢复重新建立有效宿主，回调受环境版本约束。

## 层级与验收

桌面层位于普通应用下、桌面上。WinEvent 与有界观察计时器修复最小化和层级；桌面被系统提升时临时使用原生置顶组，应用恢复后降回桌面层。始终置顶使用固定置顶组。不拦截系统快捷键，不抢焦点。

工具窗口样式本身不保证 Win+D 行为。自动回归覆盖实际工具窗口最小化恢复、解除观察、悬浮窗口独立 HWND、横竖切换和挂起；Win+D、显示桌面按钮、Win+M、混合 DPI、多屏回退、Explorer 重启及退出清理待维护者验收。
