# 小任务栏自适应

横向与竖向任务栏按实际可用厚度布局。该能力不受实验开关控制，竖向宿主本身仍由竖向实验开关控制。

## 呈现规则

用户字体百分比只应用一次。运行时几何可小于设置编辑范围的最小比例，避免较窄的真实任务栏仍使用较大的固定画布。留白随厚度减少，主文字仅在自身也放不下时夹取实际字号。

有歌词时保留当前歌词，空间不足收起第二行或译文；无歌词时保留标题，再收起歌手或并显的歌手文字。原始文本、逐字进度和保存设置不变，空间恢复后副信息自动恢复。完整面板保留原始信息。

栏长只根据当前显示内容测量，隐藏的长副歌词不再撑大媒体栏。横向频谱适配真实高度，较薄横向任务栏的网络指标采用单行数值，按钮与命中表面限制在可用高度内；采样与音频算法不变。

## 提示与生命周期

只有真实副信息被收起时才请求通知，未知歌手占位和空白行不消耗提示机会。每次应用会话最多成功提示一次，通知失败可在宿主恢复后重试；点击定位实验页的桌面悬浮条分组，不自动开启实验或切换模式。

普通内容变化继续保留悬停和完整面板；真实位置、朝向、DPI、隐藏和宿主重建仍沿用交互保护与弹层清理。

## 验证边界

回归覆盖两轴预算、实际控件字体与显隐恢复、原始逐字帧保留、隐藏副歌词的栏长、一会话提示及托盘点击目标。实际 Web 源码截图检查三种动效档位下的混排、扫描、居中与第二行恢复。

真实任务栏、多屏混合 DPI、指针跨弹层、自动隐藏、Explorer 重启和退出清理待维护者验收。
